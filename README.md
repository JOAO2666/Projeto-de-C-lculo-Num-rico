## Sobre o Projeto
O simulador funciona como uma calculadora de precisao finita que realiza operacoes aritmeticas (+, -, *, /) controlando o numero de digitos significativos atraves de truncamento ou arredondamento. 

O programa tambem calcula o erro absoluto e o erro relativo de cada operacao, permitindo analisar fenomenos como o cancelamento subtrativo e a propagacao cumulativa de erros.
